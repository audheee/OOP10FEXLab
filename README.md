# OOP10FEXLab - Fuego BBQ Ordering System

This repository contains the final laboratory exam project for OOP10: a fast-food ordering system tailored for "Fuego: Low and Slow BBQ".

## Project Overview
The application consists of two main Windows Forms interfaces:
1. **Queue Monitor:** Displays a dual-panel screen for "Preparing" and "Now Serving" orders.
2. **Kiosk:** A self-service menu screen for placing orders.
