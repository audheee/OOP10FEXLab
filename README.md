# OOP10FEXLab - Fuego BBQ Ordering System

This repository contains the final laboratory exam project for OOP10: a fast-food ordering system tailored for "Fuego: Low and Slow BBQ".

## Project Overview
The application consists of a Windows Forms interface connecting to a MySQL database:
1. **Kiosk:** A self-service menu screen for placing orders, integrated with a remote database.
